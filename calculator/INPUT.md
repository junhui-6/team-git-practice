# 模块2：数字输入与显示（Issue #12）

基于 PR #19 的页面实现，沿用 `inputDigit(d)`、`backspace()`、`clearAll()`，供按钮和后续键盘模块共用。输入参数为单个字符字符串。

双击 `index.html` 可在浏览器中使用。运行输入回归测试（需 Node.js 18 或更新版本，无第三方依赖）：

```sh
node --test calculator/tests/input.test.cjs
```

输入过程保存字符串，保留 `12.`、`0.00`；同一个操作数只允许一个小数点，以小数点开始时自动补零，重复前导零不累积。退格只删除当前输入的最后一个字符，删空显示 `0`，但内部仍为空，因此不会把尚未输入的第二个操作数当成零参与计算。

选择运算符后主显示区显示 `0`，表达式区保留前一个操作数及运算符。计算完成后直接输入数字或小数点开始新计算；先选择运算符则接着上次结果计算。计算结果上的退格沿用原实现：不修改结果。C 清除输入、运算符、历史结果和错误状态。

手动验收：

| 按键 | 预期显示 |
| --- | --- |
| `1 2 . 5` | `12.5` |
| `C 1 . . 2` | `1.2` |
| `C . 5` | `0.5` |
| `C 1 2 . 5 ←` | `12.` |
| `C 1 ← ←` | `0` |
| `C 1 2 + 3 ←` | `0`，表达式仍为 `12 +` |
| 接着输入 `4 =` | `16` |
| `C 2 + 3 = + 4 =` | `9` |
| `C` | 显示 `0`，表达式清空 |

自动测试执行实际页面脚本并检查显示文本及操作序列；使用最小 DOM 替身，不覆盖浏览器布局及真实点击事件。

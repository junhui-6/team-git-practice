# 基础计算器

对应 Issue #9「开发一个计算器」。用标准库实现，零第三方依赖。

## 功能

- 加、减、乘、除四则运算
- 运算符优先级（乘除先于加减）与括号
- 连续运算（链式表达式 + 用 `ans` 引用上一次结果）
- 除以零、非法字符、括号不匹配等异常输入均有友好提示，不崩溃

## 运行

```bash
# 交互模式
python -m calculator
```

交互示例：

```
>>> 1 + 2 * 3
7
>>> ans / 7
1
>>> (1 + 2) * 4
12
>>> 1 / 0
错误: 除以零是不允许的
```

## 测试

```bash
# 在仓库根目录运行
python -m unittest discover
```

覆盖：四则运算、优先级、括号、连续运算、负数、除零、非法输入、结果格式化。

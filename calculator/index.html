边界场景一键演示

场景1 · 除以零：1 ÷ 0 = 应显示友好错误，不崩溃
场景2 · 超大数字/溢出：9999999999 × 9999999999 = 应科学计数法或提示
场景3 · 连续按等号：5 + 3 = = = 重复上次运算（每次 +3 → 11、14、17）
场景4 · 未输入数字直接按运算符：开机后直接按 ÷ + −，应忽略并提示
边界处理定义：
1. 除以零：result 设为 Error，显示屏变红，需按 C 重置
2. 超大数字/溢出：结果 ≥ 1e21 或非有限数时，用科学计数法 toExponential(8) 显示
3. 连续按等号：记录上次运算 (prevOp, prevOperand)，按 = 时若 currentInput 为空且上次是 equal，则重复 prevOp 运算
4. 空输入按运算符：若 previousValue 为空且 currentInput 为空，忽略运算符并闪烁提示
